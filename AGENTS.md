# Desarrollo con OpenSpec

Usa las skills de `.agents/skills/` para explorar, proponer, actualizar, implementar, sincronizar o archivar cambios según lo que pida la tarea. Consulta `openspec/specs/` para conocer los requisitos vigentes y `openspec/changes/` para los cambios en curso.

Desde la raíz del repositorio, ejecuta `npm ci` si las dependencias aún no están instaladas. En los ejemplos de las skills, ejecuta `openspec <argumentos>` como `npm run openspec -- <argumentos>` para usar la versión fijada en `package-lock.json`.
